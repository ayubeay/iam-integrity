# SOUNDKEEP — Creative Review Sessions
**Status:** RESERVED Future Architecture · **Reserved:** July 21, 2026
**Parent:** SoundKeep Collaboration Workspace (module within, not separate product) · Roadmap position 7.
**Origin:** Reddit field pattern — creators often want honest feedback, arrangement ideas, drum suggestions, production/mix critique, songwriting opinions — NOT a permanent collaborator. Review is different from collaboration; today it fragments across Reddit > comments > DM > Instagram > Drive > Dropbox > voice notes > email.

# Core Doctrine
Not every creator seeks a collaborator; many need experienced listeners who provide constructive feedback before the next version. SoundKeep preserves creative feedback as part of the project's evolution instead of scattering it across platforms.

# Review Requests
Songwriting critique · arrangement review · melody feedback · drum pattern suggestions · guitar/bass/vocal performance review · harmony suggestions · mix review · mastering review · sound design review · general listening session. Each request connects to a specific project and version.

# Review Sessions
Reviewer, review type, timestamp, version reviewed, overall assessment, structured comments, suggested improvements, follow-up discussion — every review becomes part of the project's permanent creative history.

# Timeline Integration
Feedback attaches to versions: Version 3 (arrangement review, drum suggestions, mix notes, melody feedback) > Version 4 > Version 5 > final release. Creators see exactly which feedback influenced each revision.

# Contextual Feedback
Comments tied to moments — intro, verse, chorus, bridge, solo, outro — synchronized with the project timeline, never disconnected conversations. (Pairs with the Moments & Timeline reserve.)

# AI Review Intelligence
Summarize multiple opinions; detect recurring recommendations ("most reviewers suggest simplifying the chorus"; "three collaborators independently recommended a tempo increase"); identify unresolved and conflicting feedback; track implemented improvements; compare revisions; generate review summaries. AI organizes and synthesizes — never replaces creative judgment.

# Reviewer Discovery
By genre expertise, instruments, production/mixing experience, songwriting background, languages, collaboration history, community reputation.

# Creative History
Review requests, reviewer participation, feedback history, version evolution, accepted and declined recommendations, final implementation — a complete record of how critique shaped the work.
