# Core Doctrine
Music is rarely created by one person. Collaboration should happen around a shared project with full visibility into its evolution — preserving not only the finished work but the collaborative process that produced it.

# Validated Pattern (field evidence, July 2026)
Observed repeatedly across Reddit music-collab communities: creators use Reddit only as the discovery layer ("need fresh ears" > "need drum ideas" > "maybe collaborate"), then immediately scatter to Instagram DMs, Discord, email, Drive, Dropbox, WeTransfer — where the actual collaboration fragments. People are not asking for a marketplace; they are asking for trusted creative collaboration with a home.

# Collaboration Requests
Published per-project: vocalist, guitarist, drummer, bass, keys, producer, mixing engineer, mastering engineer, lyric writer, composer — each request attached to a specific creative project.

# Contributor Profiles
Roles, genres, instruments, vocal range, languages, remote availability, collaboration preferences, portfolio, previous collaborations — discovery by project requirements, not random outreach.

# AI Scratch Content
AI-generated content as temporary scaffolding only: scratch vocals, placeholder harmonies, temporary narration, melody demonstrations, arrangement references — communicating intent until human collaborators contribute.

# Shared Workspace
Per project: timeline, assets, lyrics, stems, MIDI, notes, version history, feedback, discussion, task assignments — one workspace, never scattered services.

# Contribution History
Contributor, contribution type, version, timestamp, revision history, approval status, milestone — a transparent record of how the work evolved. (Receipts doctrine applied to creative contribution.)

# Collaboration Search
"Find female rock vocalists." "Find jazz pianists available remotely." "Find producers experienced with electronic music." "Show projects seeking mastering engineers."

# AI Assistance
Match compatible collaborators; recommend contributors by project need; detect missing roles; organize assets; summarize progress; highlight unresolved tasks; track completion. The AI coordinates; humans create.
