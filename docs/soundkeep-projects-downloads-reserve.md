# SOUNDKEEP — Projects & Downloads Reserve
**Status:** RESERVED · **Reserved:** July 19, 2026 (committed July 21)

# Core Thesis
The Vault should not only preserve imported music. It becomes the default destination for every asset created, imported, downloaded, purchased, recorded, or generated inside the SoundKeep ecosystem. The user never wonders "Where did my file go?" The answer is always "It's in your SoundKeep Vault."

# Product Philosophy
Every action creates or updates a permanent object in the user's Vault: imports, downloads, purchased beats, sample packs, recorded vocals, playlists, AI-generated stems, AI mastering, DJ crates, shared collaborations, project exports.

# Projects
Projects are first-class citizens — living workspaces containing every asset of one creative effort: name, description, artwork, collaborators, status, timeline. Assets: audio (demos, masters, stems, instrumentals, acapellas), creative (lyrics, chords, notes, voice memos, references), production (BPM, key, plugins, mix notes), publishing (copyright, licensing, credits, release date), history (versions, activity, import/export history).

# Intelligent Downloads
Downloads auto-organize on arrival: Music, Purchased Music, Free Downloads, Sample Packs, Drum Kits, Loops, Presets, DJ Pools, Podcasts, Audiobooks, Educational Content, Templates. Users may reorganize later.

# Auto-Ingestion
Everything generated inside SoundKeep enters the Vault automatically: record vocal > Project; create playlist > Library; download sample pack > Downloads; purchase beat > Purchased Assets; AI stem separation > Project Assets. No manual save wherever possible.

# Rich Asset Metadata
Audio: title, artist, album, BPM, key, genre, mood, duration, file type, bitrate, artwork. Purchased: seller, marketplace, invoice, license, purchase date, usage rights. Project asset: version, created by, collaborators, related files, parent project.

# Vault Lifecycle
Import > Organize > Create > Download > Purchase > Collaborate > Publish > Archive — every stage connected.

# Universal Search
Search eventually understands filenames, lyrics, BPM, key, collaborator, producer, project, tags, notes, purchase history, licenses, release status, playlists, stems. The user searches ideas — not folders.

# Long-Term Vision
SoundKeep becomes the Music Operating System. Traditional computers organize files by storage location; SoundKeep organizes by creative meaning. Not "Which folder?" but "Which project? Which song?" — everything else is discovered automatically.

# Relationship to Existing Reserves
Extends Permanent Vault, Creator Library, Ownership Layer. Those define where music lives; this defines how every workflow automatically feeds the Vault.

# Product Doctrine
The Vault is not passive storage. It is the living memory of the creator. Every download, recording, purchase, collaboration, project, and release becomes part of one continuous musical history owned by the creator. Nothing created inside SoundKeep should ever become an orphan file.
