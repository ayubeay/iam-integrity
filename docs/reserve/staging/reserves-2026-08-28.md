## Decisions worth recording

**PICE was the closest call.** The Execution Adapter Framework owns the adapter layer;
Universal Execution Interface owns the vertical stack L1–L6. Neither owns the object between
them. EAF's unit is the *adapter* — one per provider, a runtime call contract. PICE's unit is
the *capability* — a semantic description of what an operation does, shared across multiple
bindings of the same operation. EAF's own flow places governance before the execution
contract without saying what governance evaluates; PICE supplies that object. And a local
function call has no adapter at all yet still needs the envelope. The defensible alternative
was a dated extension to EAF; it was rejected because EAF is top-level, deferred and LOW
urgency, and a large semantic-capability section would have buried the thing governance
actually consumes.

**Decision Influence became an extension, not a file.** Computable Accountability already
owns the recommendation boundary — line 13's "AI may observe, score, rank, recommend…",
line 18's chain through an authorized human to execution, line 58's "a model output is a
recommendation," and a `Layers that must not collapse` section. Influence *provenance*
deepens that same invariant rather than establishing a new one.

**ETA did not survive as a reserve.** Its instrumentation content is owned by Physical System
Boundary Accounting; its claim-burden content by the Extraordinary Claim Evidence Tree. One
sentence was worth preserving verbatim and now lives in `docs/reserve/proof-before-promotion.md`.

**Temporal Evidence Admissibility is a child, not a sibling.** The Evidence Lifecycle
envelope answers *what state is this evidence in and what did it establish at time T*. TEA
answers *how fast does its decision-relevant usefulness decay, and when does it stop being
admissible.* Different question, different vocabulary, different consumers.

**HMSB survived narrowly and is scoped tightly.** Ownership Proofs owns
`possession ≠ permission`; EMAA owns hostile external machine action; Computable
Accountability owns the responsibility chain. HMSB owns only which powers remain
non-delegable to machines that are authenticated, capable and otherwise admissible. Its own
file states that if it drifts into general sovereignty prose it should be folded away.

**Nothing owned thinnest-leg or loyalty value.** Both searches were run against all 96 files
and both instruments were shown capable of producing non-empty output before their empty
results were accepted as evidence.

## Explicitly excluded

**SIGOME is outside canon.** SIGOME refers to personal sigil ritual practice. It is not a
software system, architecture mechanism, research program, product or organizational
doctrine, and no reserve was created for it. Where source material referenced SIGOME in a
place the architecture genuinely relates to an ethical institution, the reference was
redirected to HFAI; elsewhere it was deleted. **No mechanical substitution was performed**,
and HFAI is not a rename of SIGOME.

**Earthwise remains excluded**, as in Batch 1.

**Deliverable B is not in this batch.** EVIDENCE_DISCIPLINE.md and the migration of the six
2026-08-27 candidates and the Output B Top 5 into individual specs are a separate
deliverable. Batch 2 creates the `experiments/` and `tests/` structure those migrations will
land in; it does not perform the migration.

**Zircon remains reserve-only.** zircon.md records urgency LOW as a build. Nothing here
changes that.
