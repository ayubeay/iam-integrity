Status: RESERVED / NOT ACTIVE BUILD. Refinement/child of the HELIX Workspace family — not a standalone product.
Parent: HELIX Workspace (see docs/helix-ecosystem-hierarchy.md). Knowledge/curriculum owner: VKOS (docs/RESERVE-VKOS.md). Reconcile terminology against both before any implementation.
Captured: 2026-08-23. Origin signal: iCode-style physical coding/robotics education. The insight is NOT the franchise — it is removing the requirement that learners travel to a facility: bring the laboratory to the learner.

## What is genuinely new

A distributed, evidence-bearing capability-learning subsystem under HELIX Workspace: governed remote learning where **productive failure becomes evidence of reasoning**, and only designated demonstrations (not private experimentation) contribute to persistent capability credentials. No existing Workspace child reserve owns this.

## Core loop & doctrine

KNOWLEDGE → ATTEMPT → EXECUTION → FAILURE/SUCCESS → OBSERVATION → REASONING → RETRY → DEMONSTRATION → EVIDENCE → VERIFIED CAPABILITY → HARDER CHALLENGE. **Productive Failure Doctrine:** youth agents do not auto-solve; assistance is progressively bounded (explanation → question → clue → diagnostic → partial scaffold → fuller solution only when educationally appropriate). Distinguish "produced the correct answer" from "demonstrated understanding of how to reach it" — resistance to AI answer-copying is part of the architecture. Three execution environments: (1) Home Virtual Lab (software-defined labs, no special equipment); (2) Home Physical Lab (optional inexpensive hardware; program runs against real devices while Workspace records telemetry/evidence); (3) Remote Physical Lab (expensive equipment accessed remotely through governed sessions: learner → HelixWorkspace → authorization → sandbox → remote robot → execution → telemetry/evidence → capability receipt). Physical Capability Nodes remain useful as *shared infrastructure*, not mandatory storefront classrooms.

**Capability Progression Layer:** record evidence (attempt count, independent successes, failure categories, diagnostic ability, hints required, time-to-recovery, novel-problem performance, transfer, consistency, safety/governance behavior, collaboration) so "Completed Robotics Level 3" becomes a capability record ("demonstrated autonomous-navigation competency across 18 unseen trials; diagnosed 7/9 failures; transferred sensor-fusion to two environments; evidence attached").

**Boundaries (preserve):** Youth is NOT an employment system for children — learning first; any economic opportunity must be age-appropriate, jurisdiction-aware, consent-governed, routed through safeguards. Not permanent surveillance: distinguish private experimentation (free to make messy mistakes) from explicit assessments (evidence intentionally recorded). A child must have the right to experiment without every mistake becoming permanent reputation; only designated demonstrations contribute strongly to persistent credentials.
