# HELIX — Ecosystem Hierarchy (Ratified)
**Status:** Doctrine · **Ratified:** July 21, 2026

# Decision
Pathway does NOT sit under HELIXEDGE. Pathway is the execution-planning environment inside HELIX Workspace; its core engine is the Work Decomposition Engine (WDE).

# The Tree
HELIX (ecosystem and product family)
- HELIX Workspace
  - Pathway
    - Work Decomposition Engine (WDE)
    - Planning · Task Graph · Execution Pipeline · Delivery
- HELIX Marketplace (founder matching, collaboration, talent, services)
- HELIX Compute
- HELIXEDGE (physical runtime: PEG, PIL/sensor intelligence)
- vLOID (VERITY, IAM, OROS, DRIFT)
- SURVIVOR

# Pathway WDE (the reserve, restated)
Purpose: understand work before execution — not code generation. Given "make my Next.js application responsive," Pathway produces work packages, dependency graph, required skills, AI suitability, human review points, execution order, testing requirements, execution receipts. Philosophy: understanding precedes execution. Today software planning; tomorrow potentially music production, robotics missions, business workflows, research pipelines, construction — unconstrained by HELIXEDGE.

# The Complementary Split
HELIXEDGE answers: "How do we execute safely in the physical world?"
Pathway answers: "How do we understand and organize the work before execution?"
Different layers, complementary responsibilities.

# Naming Guard
SoundKeep's "Pathway" (music pathway engine) and HELIX's "Pathway" (work decomposition) are DIFFERENT systems sharing a name. Context disambiguates for now; revisit naming if both reach public surface simultaneously.
