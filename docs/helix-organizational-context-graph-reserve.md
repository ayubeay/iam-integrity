# HELIX — Organizational Context Graph (OCG)
**Status:** RESERVED Future Architecture · **Reserved:** July 21, 2026
**Parent:** HELIX Workspace / Pathway
**Origin:** ClickUp convergence analysis — "60% of human work is lost in context." ClickUp optimizes team productivity; HELIX optimizes execution governance (what work should happen, who executes, is it admissible, can it be verified and audited). OCG is the context layer that governance requires.

# Core Doctrine
Organizations do not lose work because information disappears; they lose it because context fragments across tools. HELIX preserves organizational context as a continuously evolving knowledge graph, not isolated documents, chats, or tasks.

# Graph Nodes
Projects, tasks, documents, specifications, decisions, architecture diagrams, conversations, meetings, code repositories, AI agents, human contributors, execution receipts, policies, Doctrine Packs, external systems.

# Relationships
Created by · modified by · depends on · references · implements · reviews · supersedes · generated · approved · rejected · verified · executed. Knowledge stays connected.

# Agent Context
Before work begins, agents retrieve relevant documentation, prior decisions, architecture history, execution receipts, doctrine, active collaborators, related projects, current dependencies — organizational memory, not isolated prompts.

# AI Context Intelligence
Discover missing context; identify conflicting decisions; explain why previous choices were made; recommend relevant historical work; surface forgotten knowledge; connect related projects; preserve continuity as teams evolve. AI enhances understanding; humans judge.
